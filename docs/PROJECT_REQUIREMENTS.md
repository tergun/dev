# 重点项目督办情况管理平台 - 项目需求确认书

## 1. 项目概述

本项目旨在开发一个重点项目督办情况管理平台，包括移动端小程序和PC端管理系统。该平台将用于管理和监督重点项目的进展情况、审批流程和相关文档。

## 2. 技术架构

### 后端技术栈
- 基于 JeecgBoot 框架开发
- 数据库：MySQL
- 认证与授权：JWT

### 前端技术栈
- PC端管理平台：Vue3 + Vite (基于 JeecgBoot-Vue3)
- 移动端：Uni-App (基于 jeecg-uniapp)

## 3. 功能需求

### 3.1 用户认证
- 小程序登录界面
- 账号密码认证
- 权限管理系统

### 3.2 项目目录管理
- 项目列表展示
- 项目分类管理
- 项目搜索功能

### 3.3 项目基础信息管理
#### 基本信息展示
- 调度层级
- 项目名称
- 投资主体
- 建设性质
- 总投资
- 2025年计划完成投资
- 计划开复工时间
- 计划完工时间
- 分管领导
- 责任单位

#### 访问权限
- 政府办
- 发改委

### 3.4 前期手续办理情况管理
#### 审批状态管理
1. 否定状态信息
   - 办理期限（下拉选择）
   - 办理层级（下拉选择：旗级、市级、自治区级、国家级）
   - 组卷情况（详情按钮）
   - 审批情况（详情按钮）

2. 肯定状态信息
   - 审批文件上传功能

3. 无需办理状态
   - 说明材料上传
   - 证明材料上传

#### 访问权限
- 项目牵头部门

### 3.5 项目进展管理
- 文字描述进展情况
- 形象进度百分比（下拉选择）
- 访问权限：项目牵头部门

### 3.6 活跃度监测
- 7天内更新内容监测
- 各模块更新状态显示
- 无更新时的活跃度维持机制
