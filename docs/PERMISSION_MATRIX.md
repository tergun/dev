# 权限矩阵设计文档

## 1. 用户角色定义

### 1.1 超级管理员（政府办）
- 角色代码: SUPER_ADMIN
- 描述: 系统最高权限管理者

### 1.2 发改委
- 角色代码: REFORM_COMMISSION
- 描述: 项目监督管理部门

### 1.3 项目牵头部门
- 角色代码: PROJECT_LEAD_DEPT
- 描述: 具体项目的负责部门

### 1.4 普通部门
- 角色代码: NORMAL_DEPT
- 描述: 其他参与部门

## 3. 数据权限控制

### 3.1 超级管理员
- 可查看和操作所有数据
- 可分配和回收其他角色权限
- 可设置部门年度任务和权限

### 3.2 发改委
- 可查看所有项目数据
- 可编辑项目基础信息
- 可查看但不能修改前期手续和进展信息

### 3.3 项目牵头部门
- 只能查看和操作被分配的项目
- 可更新项目前期手续办理情况
- 可更新项目进展和形象进度
- 权限受年度任务分配影响

### 3.4 普通部门
- 只能查看被授权的项目信息
- 无编辑权限
- 权限受年度任务分配影响

## 4. 特殊权限控制

### 4.1 文件操作权限
- 文件上传: 项目牵头部门和超级管理员
- 文件下载: 所有角色
- 文件删除: 仅超级管理员

### 4.2 数据导出权限
- 完整数据导出: 超级管理员和发改委
- 部分数据导出: 项目牵头部门（仅自己负责的项目）

### 4.3 统计分析权限
- 全局统计: 超级管理员和发改委
- 部门统计: 项目牵头部门（仅自己部门数据）

## 5. 权限时效性控制

### 5.1 年度权限管理
- 权限有效期与年度任务挂钩
- 超期自动失效
- 可提前终止或延期

### 5.2 临时权限管理
- 支持临时权限分配
- 明确时效期限
- 自动失效机制

## 6. 权限审计

### 6.1 权限变更记录
- 记录权限变更操作
- 记录操作人和时间
- 记录变更原因

### 6.2 权限使用记录
- 记录权限使用情况
- 异常权限使用预警
- 定期权限审计报告
